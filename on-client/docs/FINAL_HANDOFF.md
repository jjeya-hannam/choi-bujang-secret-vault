# 7일차 최종 인수인계

## 인수 상태

학생 소유 PC 관제 기능, 실행기, 소스 포장, 재현 방법과 내부 검수를 마무리했습니다. 2026-10-26 사용자가 Windows에서 정상이라고 확인했습니다. 이는 사용자 실행 보고이며, 개발 에이전트가 Windows 기기에서 방화벽·이벤트 값이나 .lnk를 직접 확인했다는 뜻은 아닙니다. 운영 연동과 공식 최종 제출은 별도입니다.

## 1~7일차 결과

1. 기존 22단계·Vercel 자료실을 보존하고 접속 현황, 기록 근거, 제안/실행 구분을 핵심 흐름으로 유지했습니다.
2. 실행 PC에서 CPU 사용률·메모리 사용량·디스크 일반 사용자 가용 공간을 수동 측정하고 단위와 시각을 표시합니다.
3. 네트워크 구성 개수만 읽습니다. Windows에서는 방화벽 ActiveStore와 System/Application 최근24시간 경고·오류 합계를 읽고, 권한·플랫폼 실패는 확인 불가로 남깁니다. 공격 탐지 결과로 계산하지 않습니다.
4. 실측4카드, 최근8회 메모리 이력, 수동 조회·취소·시간 제한·오류 표시를 갖췄습니다. 기존 보안 정책과 CSS를 유지합니다.
5. 독립93개 시험, Node24.19.0 검증, Mac 실제 브라우저·실측을 확인했습니다. 독립 에이전트가 새 폴더·공백 경로에서 묶음42개 파일 해시, Node24 환경 진단, 예제 HTTP 판정과 실제 PC 조회를 재현했습니다. 이 수치는 최종 안내를 추가하기 전 검증 묶음 기준이며 최종 manifest의 목록과 구분합니다.
6. 학생용 실행 묶음, 환경 진단, Windows .cmd/macOS .sh와 선택적 사용자 바탕화면 바로가기 생성기를 준비했습니다. Node 실행 파일이나 비밀값은 배포하지 않습니다.
7. 이 안내와 실행 묶음의 manifest, 내부 검증 기록으로 시연·재현·한계를 인수인계합니다.

## Windows에서 켜기

Git과 Node24.19.0이상24.x가 필요합니다. 기존 폴더를 덮어쓰지 말고 새 폴더로 clone합니다. 이미 압축을 풀었다면 on-client 폴더에서 시작기를 실행합니다.

```bat
git clone https://github.com/jjeya-hannam/choi-bujang-secret-vault.git gamst-final
cd gamst-final\on-client
tools\start-portable.cmd
```

실행기는 환경을 확인하고 이 프로세스의 포트를5189로 지정합니다. http://127.0.0.1:5189 를 열어 보호 현황의 「내 PC 상태 조회」를 누르세요. PC값은 실측, 보안 기록은 예제이며 SDP 미연결과 구분됩니다. 종료는 Ctrl+C입니다. 다른 포트가 필요하면 on-client에서 `npm run student` 또는 `npm run student:demo`를 사용하고 실제 시작 메시지의 주소를 따릅니다.

## 3분 시연 순서

1. 첫 화면의 예제 표시·SDP 연결 없음과 PC 미조회 표시를 확인합니다.
2. PC 조회를 눌러4개 카드의 값·단위·시각을 확인합니다. 한 번 더 눌러 이력이 현재 값과 구분되는지 확인합니다.
3. Windows 항목의 결과 또는 확인 불가 이유를 확인합니다. 경고·오류는 침해 건수가 아닙니다.
4. 업무 앱에서 학습 자료실은 예제 허용, 개발 저장소는 예제 거부, 확인할 업무 앱은 추가 확인을 요청합니다. 이를 실제 운영 권한 변경으로 설명하지 않습니다.
5. 보안 기록의 근거·규칙·unknown을 확인합니다. 실제 AI·보안 조치는 자동 실행하지 않습니다. 미지원 기능을 성공으로 표시하지 않습니다.
6. 종료 후 시작기로 다시 엽니다. PC 이력은 브라우저 메모리에만 있으므로 새로고침하면 사라집니다.

## 문제·복구

- Node 진단 실패: Node24.19.0이상24.x와 SQLite/statfs 지원을 확인합니다. 루트 자료실용 Node와 on-client 지원 범위를 섞지 않습니다.
- 포트 사용 중: 다른 프로세스를 강제 종료하거나 방화벽을 낮추지 않습니다. 기존 실행 창을 확인하거나 직접 선택한 포트로 실행합니다.
- Windows 읽기 실패: 관리자 승격·실행 정책 우회 없이 확인 불가로 둡니다. 다른 Windows 설치 경로는 지원하지 않을 수 있습니다.
- .lnk가 필요하면 `powershell -NoProfile -File tools\create-shortcut.ps1`를 사용합니다. 기존 바로가기는 덮어쓰지 않습니다. 정책이 막으면 .cmd를 직접 실행합니다.
- 이전 버전으로 돌아가려면 별도 새 폴더에 그 버전을 받습니다. 기존 .env·자격·DB·기록을 삭제하거나 복사하지 않습니다. git reset --hard는 사용하지 않습니다.

## 범위와 출처

제공 기능은 기존 신원/기기/세션·접속/기록·AI/조치 호스트입니다. 학생 기능은 렌더러·PC 읽기 모듈·학생 로컬 호스트·실측 관제·환경 진단·소스 포장과 실행기입니다. 원본 서버·공통 화면·인증·운영 DB는 보존했습니다.

로컬 HTTP의 Host/Origin/헤더·GET 제한은 다른 웹사이트 요청을 제한하며 이미 PC에서 실행되는 악성 프로세스를 신뢰할 수 있게 만드는 인증은 아닙니다. CPU 등 관측은 PC 전체의 보안 판정이 아닙니다. 사용자 이름·IP·MAC·로그 본문을 수집하거나 외부로 보내지 않습니다.

학생용 source-app.tar.gz + PORTABLE_SOURCE_MANIFEST.json + SOURCE_RUN.md는 공식 package-app/승인 host의4파일을 대신하지 않습니다. 공식 host·사진 접수·최종 제출은 운영 경로가 준비된 뒤 별도 처리해야 합니다. 이번 인수에서 점수·순위·운영 방어 성공을 주장하지 않습니다.
